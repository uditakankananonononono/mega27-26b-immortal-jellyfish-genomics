# Benchmark scope and limits

Two limited contrasts probe whether particular design choices change measured strong-locus yield. Neither is a fair benchmark against existing annotation pipelines. The first contrast isolates the multi-species query design. On the annotated Clytia calibration genome, the single frozen mapping output was re-analyzed twice per gene in a paired design: once counting only the human-derived query (the human-only design a database-centric project would use), and once counting the full multi-species query set (human plus Hydra, Clytia, Nematostella and Acropora homologs). Both arms share the same genome, thresholds, clustering and tBLASTn output, so the contrast isolates the query set with no other degrees of freedom. Recovery is defined by the frozen strong-locus criterion.

Human-only queries recover 27 of 47 panel genes (57.4%); the multi-species arm recovers 35 (74.5%). The eight genes recovered only through non-human queries are C9orf72, FUS, HSF1, OPTN, PTEN, SQSTM1, TFEB, TP53. These eight labels lacked a strong hit from a human-only query but cleared the cutoff with a closer cnidarian query; without independent truth labels, we cannot say whether each is a true-positive recovery. Per-gene results are in results/x-benchmark-recall.json. The contrast is a paired re-analysis on identical genomes, thresholds, clustering and tBLASTn output. The +17 percentage point strong-locus yield difference is attributable to the query set under these rules, but true-positive recall requires independently known gene identities.

The second contrast is direct assembly search against a narrow database lookup, not a replacement for provider-published gene models. On 2026-09-27, live NCBI eutils queries for each of the 47 panel genes against T. dohrnii (organism-qualified, gene name in all fields) returned zero gene-database and zero protein-database records for 47 of 47 genes (results/x-desert-audit-bc.json; the closed phase's panel-A audit, results/desert_audit.json, shows the same pattern for the repair/telomerase panel). That exact NCBI query route yielded zero entries, not zero public gene annotations. The genome-first pipeline maps 35 of the 47 panel genes in the main T. dohrnii assembly alone (35 in the fragmented Oviedo assembly), 35/47 strong-locus calls versus zero hits in that NCBI query route, without a shared truth set that establishes biological recall. The comparison is limited because the Kyushu provider separately published high-confidence gene predictions and expression data; a fair claim of method superiority would test those models, not only an NCBI lookup. Our mapped calls have coordinates, e-values and scores; the exact NCBI query returned no named records. Methodologically the benchmark arm is honest about asymmetry: the two retrieval routes produce different evidence types, and the comparison is detected-record yield under specific retrieval routes, not biological recall or statistical superiority.
