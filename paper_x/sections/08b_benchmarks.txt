Two benchmark contrasts measure whether the design choices pay off. The first contrast isolates the multi-species query design. On the annotated Clytia calibration genome, the single frozen mapping output was re-analyzed twice per gene in a paired design: once counting only the human-derived query (the human-only design a database-centric project would use), and once counting the full multi-species query set (human plus Hydra, Clytia, Nematostella and Acropora homologs). Both arms share the same genome, thresholds, clustering and tBLASTn output, so the contrast isolates the query set with no other degrees of freedom. Recovery is defined by the frozen strong-locus criterion.

Human-only queries recover 29 of 47 panel genes (61.7%); the multi-species arm recovers 38 (80.9%). The nine genes recovered only through cnidarian queries are APP, ATG5, BECN1, FUS, INSR, MTOR, PARK7, PTEN, SIRT6. These are exactly the genes where human-cnidarian divergence has eroded pairwise similarity below the strong-locus threshold while a closer cnidarian homolog still clears it - the false-negative class the multi-species design was built to catch. Per-gene results are in results/x-benchmark-recall.json. The contrast is a paired re-analysis on identical genomes, thresholds, clustering and tBLASTn output, so the +19 percentage point recall gain is attributable to the query set alone.

The second contrast is genome-first against database-first, the design this project replaces. On 2026-09-27, live NCBI eutils queries for each of the 47 panel genes against T. dohrnii (organism-qualified, gene name in all fields) returned zero gene-database and zero protein-database records for 47 of 47 genes (results/x-desert-audit-bc.json; the closed phase's panel-A audit, results/desert_audit.json, shows the same pattern for the repair/telomerase panel). A database-first project therefore has recall 0/47 on this organism. The genome-first pipeline maps 38 of the 47 panel genes in the main T. dohrnii assembly alone (37 in the fragmented Oviedo assembly), a recall of 38/47 (80.9%) against 0/47 (0.0%) for the database route. The benchmark being beaten is not a strawman: gene- and protein-database lookup is the standard first move for non-model organisms, and for annotation-desert species like T. dohrnii it simply returns nothing. Every genome-first call carries coordinates, e-values and a confidence score; every database-first call is an empty set. Methodologically the benchmark arm is honest about asymmetry: the two routes answer the same question (is this gene present in this organism) with different evidence types, and the comparison is recall, not statistical significance.
