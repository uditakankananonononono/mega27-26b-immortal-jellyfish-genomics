# P1 #6 RNA-seq exploratory sampling plan, locked before looking at read-count outcomes

Date: 2026-09-27 19:08 IST. This is an amendment to the original targeted six-mate full-run plan because six paired FASTQ files total over 11 GB and over 70 million read pairs; a 120-second foreground command ceiling and 1.9 GiB RAM make full mapping impractical. The previously attempted Medusa mate mapping in the predecessor sandbox yielded no saved analyzable results; this replacement sandbox has not mapped any of the three RNA-seq runs at this lock.

Inputs: PRJNA603209, SRR10967543 (Polyp1), SRR10967540 (Medusa1), SRR10967537 (RevPolyp1). ENA run/experiment metadata verified live. Stage assignments are the source's experiment titles, not inferred. Paired Illumina short reads; capture each mate separately to retain parity. Full ENA compressed byte sizes are frozen in experiments/x_rnaseq_reversal.py and each must exactly match before sampling. Gzip integrity is required. Sample read IDs by original FASTQ ordinal, every 100th pair starting at 1 (zero-based ordinal %100==0), from both mates, independently and identically, without replacement. This is an approximately 1% systematic subsample and not a biological replicate. Save sampled mates with expected count ceiling(total reads/100), plus full-file checksum and exact count from ENA. Never use a partial download. If full-download path fails, label data unavailable and do not promote a partial sample.

Mapper: generate 37 windows for 40 targets using existing x_rnaseq_refprep.py and frozen panel-B/C plus ACTA1 locus. Minimap2 2.28 short-read preset `-x sr`, primary alignments only, MAPQ >=20, locus span +/-2 kb. Use 10k sampled reads per foreground chunk, cursor saved only after mapper rc=0 and atomic state write. Count primary mapped reads and target/ACTA1 overlaps. Deduplicate paired reads by pair ID for the primary comparison if both mates map; report mate totals separately. Normalize per million sampled reads mapped at MAPQ>=20 to target reference, and ACTA1 ratio separately (ACTA1 may itself vary); do not call these genome-wide TPM/CPM, because the reference is target-enriched. Do not calculate inferential differential expression: n=1 library per condition in this selection, low expected counts and no cyst intermediate. Report only descriptive detection and ratios with limits and zeros honestly; if target counts are below 10 unique mapped pairs in any stage, mark that gene inconclusive. No ATG5 duplication/causal/function claim follows from transcript counts.

The exact total six compressed bytes from ENA, hashes and sample counts will be recorded after complete download. Any deviation or threshold change is labeled and justified here before results are read.
