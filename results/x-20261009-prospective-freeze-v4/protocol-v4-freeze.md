# Prospective per-label query eligibility protocol v4
SCIENTIFIC DESIGN ACCEPTED FOR FREEZE. Execution remains gated. 2026-10-09.

## Single primary endpoint and claim limits
Primary endpoint is D/N: D enrolled retained target labels with at least one merged locus scoring >=100 bits, divided by N enrolled retained target labels. Maximum N10; minimum N5. N0 is 0/0, undefined (not 0%). N1-4 is descriptive-only. N5 is an operational reporting threshold with no statistical power rationale. All endpoint reporting remains descriptive, including N>=5. No powered or confirmatory inference is claimed. Every fixed-panel label has a disposition, even empty searches, errors, cap failures and violations. A second fixed-panel denominator of10 is secondary, not the primary endpoint. No orthology, lifespan, disease mechanism, copy-number, biological recovery or calibrated significance claim follows, even when N>=5 and controls pass. This is a computational detection endpoint.

Old union32 is POST-HOC46/74 name-filtered saved-HSP arithmetic, not a preregistered baseline. Five benchmark gains are arithmetic, not biology. Original robustness gate stays blocked.

## Selection rationale
Ten finite hypothesis-panel labels were chosen by the author from human curated proteostasis/autophagy/neurology functions, not by Clytia or other-genome hit data. This is not a random sample or exhaustive gene list. target-rationale-v3.json contains accession/version, exact observed URL, curated function/disease excerpts and narrow per-label rationale; raw source JSON is preserved. No cnidarian target candidate search has opened in this preparation. PRKN is the canonical label with PARK2 an explicitly frozen search alias, not a second endpoint.

## Order and blind review
Design and fixed target/control specifications precede discovery. Independent eligibility review records A-E without any new Clytia scores. A separate execution session receives released queries only after the committed enrollment manifest and eligibility decisions. Final result review is separate from eligibility review. Public remote commit receipt before discovery is a minimum witness weaker than an independent third-party time anchor; local author dates are insufficient. No discovery, enrollment, smoke or alignment has occurred under this protocol.

Scientific design review accepted this protocol as resistant to post-hoc eligibility, not as a biological result. Eligibility review has seen record existence only for BAG3 A0A9W9Y8E5 (Desmophyllum pertusum) and PARK2 T2MIZ5 (Hydra vulgaris), no eligibility decision or Clytia score. Candidate decisions must rely on enrollment-manifest evidence. No further reviewer searches before that manifest.

## Finite search and enrollment
See target-search-spec-v4.json for exact20 provider/label queries. One snapshot, no later requery. For either provider count>100: overflow disposition, no narrowing/rescue. Transport error: operational error, no retry. Metadata sorted BEFORE primary sequence/domain review: reviewed UniProt, unreviewed UniProt, RefSeq, then ASCII accession and ascending version. Alias duplicate records collapsed before cap, with crosswalk disclosed. First20 sorted accession reviews per label maximum; first all-pass candidate only, exactly one provisional query/label. If first20 fail, cap failure with no candidate21. No source-prefix-driven selection or post-score swap.

Every candidate gets binary PASS/FAIL with original source URLs/evidence for:
A: versioned primary accession/sequence, cnidarian taxon, original submitted exact gene/product. Reject ProtNLM-only, ligand/receptor/pathway-phrase, unnamed or wrong-gene support.
B: primary domain architecture supports target family; reject fragments, ambiguous residues, incomplete architecture or unresolved repeated-model concern.
C: independent primary evidence discriminates exact paralog where close paralogs exist. Shared domains/transferred names alone fail.
D: no historical aligned accession, synonym, sequence, isoform or model lineage. Seen ledger is a minimum inventory, not proof of completeness. Audit all released/recovered historical FASTAs and accessions before passing. Missing lineage/alias evidence fails; no same-protein rescue through a new accession.
E: deterministic source priority, first20 cap, one-per-label, cheap duplicate clustering and closed control matching applied. Preparation team computes D/E mechanics; reviewer independently recomputes.
Ambiguity means FAIL, permanently unaligned in this cohort. Every reviewed candidate, reason and unused source record is disclosed. No re-review after outcomes.

## Cheap sequence duplication and post-alignment overlap
prospective_algorithms_v3.py defines global Needleman-Wunsch match1/mismatch-1/gap-1, diagonal/delete/insert ties. Identity is identical paired residues/paired residues; coverage paired residues/longer length. >=90% identity AND >=80% coverage forms an edge. Connected components retained lexical first(label,accession), no replacement for excluded labels. This is a cheap redundancy filter, not evidence of genomic-locus independence. Three synthetic test vectors specify exact canonical-output SHA256 for clustering, scrambles, control matching and inclusive overlap. An independent protocol-text implementation matched all3 expected outputs/canonical hashes, and this code matched3/3; this is algorithm validation, not Clytia outcome evidence. No genome alignment is performed by this code.

Post-alignment secondary report takes each retained label's best qualifying merged locus, deterministic tie by contig ASCII/start/end. Same-contig inclusive intervals sharing >=1base form connected components, ignoring orientation conservatively. Report label D/N and overlap-merged detected components divided by total N alongside all overlaps and intervals. Do NOT edit enrollment or primary denominator due to overlap. Best-locus and all-loci evidence remains available; merge rule and original scoring code are pinned in later execution amendment before any alignment.

## Real proteins, scrambles and stop rules
Real-null fixed pool is20 unrelated exact-name cnidarian proteins from one accession-ascending first100 UniProt snapshot of actin/tubulin/GAPDH/enolase/citrate-synthase/malate-dehydrogenase product searches. Reviewed exact-gene scout returned0, then this single pre-discovery protein-name snapshot was used; no further expansion. Snapshot URL, full raw100 records, selected sequences/versions, original aliases and InterPro/Pfam family support are preserved. Pool selection: exact closed names, nonfragment, standard20-AA, length>=250, family-domain support; no Clytia hits inspected. The first100 pool is biased and not a representative null distribution. These housekeeping families are highly conserved and may genuinely map well. Thus the >10% background stop may fire due to conserved housekeeping biology unrelated to target labels; it does not estimate the false-positive rate or test pathway specificity. Sparse length coverage is intentional and fully reported, never hidden. The pool is unchanged from v3 and fixed before discovery.

Seen audit remains NOT DONE: exact-accession intersection is empty only. Full alias/lineage/isoform/sequence exclusion against all recovered historical FASTAs is a mandatory pre-enrollment gate for both targets and nulls. Reject any pool member in a target family or seen accession/alias/model/isoform/sequence. Eligibility reviewer confirms those exclusions before matching. In retained-label ASCII order select one unused eligible pool accession with length ratio0.8..1.25 inclusive; smallest absolute length difference then accession ASCII. Exactly one real control/target maximum. Closed matching happens before alignment. Matching uses actual retained ENROLLED QUERY sequence length, not the human rationale protein length and not an inferred/reference Clytia locus length. Candidate taxon may be any allowed cnidarian; no assumption that it is Clytia. Human lengths are only pre-discovery feasibility proxies. Match enrolled retained labels only, after identity/seen review and before any score. An unmatched label stays in primary D/N, with unmatched status disclosed; it does not disable all other labels. Minimum matched M=5 permits reporting the real-background comparison for the matched subset only. If M<5 or M0, that comparison is insufficient/descriptive-only, not failed biology. N0 remains undefined. No expanded pool or re-match after outcomes. No matched-only endpoint replaces primary D/N, and unmatched targets receive no control-qualified interpretation.

If real-control detected/M>0.10 (M>0), report target-label yield NOT INTERPRETABLE against this background. A <=10% rate cannot validate unmatched labels or biological recovery. The background comparison applies only to the matched enrolled subset; disclose its target detection count and denominator separately, without relabeling it a primary endpoint. Exactly10% does not trigger. High background may be genuine mapping of conserved unrelated cnidarian proteins, not a false-positive rate. Report it honestly; no engineered negative controls or tuning to force low background. D/N remains disclosed regardless of this stop.

100 deterministic composition/length scrambles/retained target are low-bar sanity checks ONLY. SHA256 stream and Fisher-Yates details are in code/spec. A scramble>=100 bits flags sanity failure, but never removes original rows or changes D/N. Real controls and sanity rates are secondary; no "control-qualified yield" competing endpoint remains.
